# Contributing

Install `.[dev,http,mcp]`, run `pytest -q` and `ruff check src tests`.
Never include credentials or harvested live results in patches. Use synthetic fixtures.
New adapters need official access/terms, free-plan exhaustion evidence, quota scopes/reset evidence,
engine provenance (or unknown), capability declarations, and failure-path tests.
Unknown billing means held, not enabled. No CAPTCHA bypass, identity rotation, paid fallback or arbitrary hosts.
Keep routing in Router and all interfaces on the same public contract. Avoid heavyweight dependencies.
